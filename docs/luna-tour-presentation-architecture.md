# Luna Tour 展示层架构：它怎么跟主地图和工具共处

> 2026-07-13。可视化版本：见本文末尾的 artifact 链接。

**最重要的一句：Luna Tour 没有自己的地图。** 它跑在你原本那张主地图上 —— 同一个
MapLibre 实例、同一批数据图层、同一套工具。所有的复杂度都来自这个决定。

## 2. 三条共处规则

### ① 命名空间隔离 —— `lt-` 前缀

`mapTourHandle` 往地图上加的每一个 source / layer / marker 都以 `lt-` 开头，
`clearOverlays()` 精确移除它加过的每一个。所以 tour 结束后，主地图回到它原来的样子
—— **不是「重建」，是「没被动过」**。

但共用一张地图就有**叠放顺序**问题：宿主的地铁线 / 测距 / 配套面板是**异步挂载**的，
会盖到 tour 的 pin 上面。所以 handle 有一个 `raiseTourLayers()`，在宿主图层挂载后把
tour 图层顶回最上层（还会自重试几次去追那个异步挂载）。

### ② chrome 门 —— 工具不是被删掉，是被**让位**

```tsx
{(!tourCode || toolsRevealed) && ( …指标条 / 工具卡 / 搜索 / 筛选… )}
```

播放时这些全部隐藏（客户看的是房子，不是仪表盘），但**一个都没卸载**。

而 `toolsRevealed` 直接等于「**tour 被暂停了**」（`isPaused`）。客户点一下屏幕暂停提问的
那一刻，整套地图工具**原地回来** —— 他可以自己拖、自己筛、自己看指标，问完再继续。

**这就是「AI 带看」和「自己逛」之间的那扇门，而它只有一行判断。**

### ③ 工具复用 —— 剧本驱动的是**你的**图层

| 回调 | 它拨动的是 | 剧本什么时候用 |
|---|---|---|
| `onAreaMetric` | 区域指标热力图（指标条那套） | 讲区域涨幅时点亮 |
| `onTransit` | 地铁线图层 | 讲通勤时 |
| `onPoiCategory` | POI 图层（按品类） | 只亮要讲的那一类 |
| `onAmenities` | 配套面板 | life 拍 |
| `onMeasure` | 测距线 | 画「到地铁 0.91km」 |
| `onPins` | 项目 pin | tour 只放这几个，不放搜索结果那一片 |

进 tour 时 `areaMetric` 被强制设成 `none`，退出时**恢复用户自己存的那个** —— tour 的选择
从不写进 localStorage。同理 `showPois && !tourCode`：tour 期间关掉那几十个通用 POI 图标，
需要哪个由剧本单独点亮。

## 3. 相机：为什么是单时钟 + 每帧 jumpTo

引擎**不用 MapLibre 的 flyTo/easeTo**。它把整拍的镜头编译成一条 `CameraTrack`，然后用一个
rAF 时钟每帧采样、`jumpTo` 过去 —— 这样镜头才能和旁白音频严格同步（音频多长镜头就走多长，
靠 `camScale` 时间伸缩）。

切拍的条件是「**旁白真的播完了** + **镜头真的走完了**」，**不看 `duration_ms`**。
所以经纪在烧语音之前随便改文案，都不需要重算任何时长 —— **两段式生成之所以能干净落地，
就是靠这一条**。

### ⚠️ 2026-07-13 修的三个坑，全在这一层

我在**生成层**改了三轮运镜（锁 bearing、删 orbit、飞行压到 2 秒），**一轮都没生效** ——
因为**渲染层每帧把它覆盖掉**：

1. `cameraTrack.ts`: 相机起点写死成迪拜市中心 `[55.27, 25.2]` → 每场 tour 都从 20km 外平移过来
2. `cameraTrack.ts`: `duration_ms: 0`（**瞬切**）被 `Math.max(MIN_CUE_MS, …)` 拉成 800ms 动画
3. `AMBIENT_ORBIT_DEG = 24` + `ROTATE_DEG_PER_MS = 3°/s` —— 两条**强制自转**

> **「代码赢过 prompt」这句话反过来也成立：坏的代码同样赢过好的 prompt。**

## 4. 生成链路（两段式）

```
选客户+选盘 → 真实数据快照 → 草稿剧本 → 【经纪过目时间线】 → ✓确认 → 发布
 画像自动      DLD/POI/户型    不烧语音    改文案/AI重写/加停靠点   此刻才扣额度
 从 CRM 带出   拿不到就少讲    不发布      带 Luna 真声预演        此刻才烧语音
               一拍，绝不编

草稿期间：客户点分享链接 = 404（is_published=false）；经纪本人可预演。
缺语音时播放器**明说**「当前是机器音」—— 回落绝不静默发生。
```

## 5. 谁拥有什么（= 删除边界）

删掉 `luna-tour/` 目录 + 那几行 import，主地图**完好无损**。

| 东西 | 归属 | tour 播放时 |
|---|---|---|
| MapLibre 实例 | MapPage（常驻，不卸载） | 共用同一个 |
| 卫星底图 | 主地图 | 强制卫星（owner 定，别改） |
| 区域色块 / 3D 地标 / 地铁线 | 主地图 | 保留 |
| 通用 POI 图标 | 主地图 | 关掉；剧本只点亮要讲的那一个 |
| 指标条 / 工具卡 / 搜索 / 筛选 | 主地图 | 隐藏；**暂停即回来** |
| 项目 pin | 主地图渲染 | 只放 tour 的那几个 |
| `lt-*` 图层 / marker | Luna Tour | 由 handle 加、由 handle 清 |
| 相机 | Luna Tour 接管 | 单时钟每帧 jumpTo |
| 字幕 / 卡片 / 章节条 | Luna Tour（纯 DOM） | 浮在地图上 |
