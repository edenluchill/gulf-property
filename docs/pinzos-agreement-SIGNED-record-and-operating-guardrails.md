## 二、我的优势(合同赋予,写代码/谈判时可依仗)

1. **平台 IP 100% 永久归我**(2.1/2.5)。所有改进、衍生、AI 架构、手绘地理边界、数据模型都是我的。乙方"提建议不产生所有权"已写死(2.5 反馈条款)。
2. **25% 平台毛收入,防稀释、独立于持股、永不重谈**(5.1d)。这是命根子,不受融资/稀释/换股影响,哪怕我一股不剩仍全额付。
3. **我控制基础设施 = 我的真实执行杠杆**。root/DNS/托管在我手(7.1);欠费 10 工作日可暂停服务(7.2);Stripe 交易时自动分账 25%(5.1b)。**合同的牙齿不在纸上,在我对部署和支付通道的控制权。**
4. **无固定到期日**(9.1),只能经买断(5.6)或违约(9.2)退出;乙方没有"5 年不续约"的刀。
5. **买断我=我说了算的价**:5.6(c) 是我的 put(我可要求乙方按公允价买我整个权益包);乙方**不能强制**清走我的费权/股权,只能强制买一份代码副本(5.6d,max $20万/0.5×费,且 25% 照付)。
6. **退出也不输**:散伙时保留全部 IP + 北美市场(9.3);公司倒闭我拿回代码和两年半产品打磨。

## 三、我要注意的 / 硬约束(写代码、设计、部署、定价时必须顾虑)

### A. 数据与隐私(第 4 条)—— 影响每一次 schema / 埋点 / 数据导出设计
- **乙方业务数据归乙方**(4.1):房源、客户、线索、成交、用户行为数据都是"公司(乙方)"的。我是**数据处理者**(4.2),不是所有者。→ **设计任何客户数据表、导出、分析时,默认这些数据属于迪拜公司,我只是代管。**
- **必须给乙方数据可移植性**(4.4):至少每月自动导出 + 只读访问。→ 若还没有"客户数据导出"功能,这是合同义务,要做。
- **我能永久免费用匿名聚合数据改进平台**(4.3):训练/分析用聚合数据 OK,但**不得可反向识别到个人**。→ 做数据分析/AI 训练时坚持匿名+聚合,别落库可识别原始数据到我私有用途。
- **DLD 公开数据可给乙方留存**(4.5),但我的**数据模型/衍生分析/精编地理边界仍是平台 IP**。→ 保护多边形 IP 的技术方案(服务端瓦片化,见 [[area-blocks-protection]])依然要做,合同没削弱它。
- 数据合规:乙方是 UAE PDPL 数据控制者,我按 Schedule 3 DPA 当处理者。→ **Schedule 3(DPA)正文还没写,签前列为待补,现在合同生效了要尽快补一份正式 DPA。**

### B. 平台可用性(6.1)—— 影响部署/运维
- 目标 **99.0% 月度可用率**(尽力,非硬保证);未达标只赔服务费抵扣,不是违约。→ 压力不大,但**别让它长期破 99%**,否则给乙方口实。计划维护要**提前 24 小时通知**才免计入。
- **持续开发含在费里,不额外收费**(6.4):bug、安全补丁、新功能都白干。**我拥有并排定路线图**,乙方需求只"善意考虑"。→ 我对做什么功能有最终决定权,但别把"善意考虑"用成"完全不理"。只有**超出路线图的重大定制**才可单独计价。

### C. 收入归集(5.1b / 6.3)—— 影响支付/计费代码
- **所有平台收入必须走指定支付通道**(6.3 反绕过),线下收款=重大违约。→ 计费系统(Stripe,见 [[stripe-billing]] [[map-metering-tiered-pricing]])必须是唯一入口;25% 分账最好在交易时自动完成(5.1b,Stripe Connect)。
- 我有**每年 2 次审计权**(升级版,查毛收入和支付通道原始报表)。→ 保留完整、可审计的收入记录;别让计费逻辑黑箱化。

### D. 里程碑(Schedule 2)—— 影响我对"独家"的杠杆
- 乙方季度下限:Q4=50 用户/$5万 → Y3=200 用户/$15万季。连续两季不达标 → 独家收窄到其实际运营国家。→ **dashboard 要能追踪这些数(付费用户数、季度平台收入),这是我判断是否收回独家的依据。** 数据源要可信(排除内部号,见 [[analytics-internal-exclusion]])。

### E. 买断触发点(5.6)—— 未来 3 年后要留意
- **上线满 3 年**同时解锁:我的 put(5.6c)、乙方的代码副本期权(5.6d)、每 3 年一次的运营条款善意重新商榷(9.1)。→ 记住"首次商业上线日"这个锚点,3 年后是关键窗口。
- 若乙方将来融资:投资人大概率要求清掉 25% royalty → 走 5.6(c) 合意全额买断,**我在谈判桌上有拒绝权**,那是我最强势的时刻。
- 全额买断价 = 费权(6× 过去12月平台费 = 收入×25%×6)+ 股权(公允价,**已扣 royalty 负担,不重复计价**)。两块相加不会"吃掉超过 50%"。

### F. IP 赔偿敞口(8.4)
- 我对"自研核心代码侵犯第三方 IP"的赔偿上限 **US$250,000**(超出一般 12 个月费上限的特别口袋)。→ 写代码引入第三方库/AI 模型/数据源时,注意授权合规,别埋 IP 侵权雷。
