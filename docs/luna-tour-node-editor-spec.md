# Luna Tour 节点式可视化编辑器 — 设计文档(2026-06-07)

> 真机反馈:时间线方向对了,但要"节点化 + 更可视 + 简单易懂 + 人和 AI 都能编辑"。
> 本文定义节点类型、视觉、布局、交互、数据映射、分步落地。代码隔离在 `luna-tour/`。

## 1. 目标与原则
- **一眼看懂**:每个能编辑的东西都是一个**有类型的视觉节点**(图标+颜色+缩略内容),不堆文字。
- **像剪辑器**:左→右时间线,按真实时长排布,卡片与时间对齐。
- **人和 AI 同源编辑**:同一套后端端点;人用拖/点/加,AI 用评论改稿,互不冲突。
- **三种基本操作**:拖动节点=移动 · 点击节点=编辑(右侧面板)· 点击空白=添加节点。

## 2. 节点类型(typed nodes)

| 节点 | 图标/色 | 显示内容 | 对应数据 | 可编辑 |
|---|---|---|---|---|
| 🏠 房源停靠 | 绿 | **房源缩略图** + 名字 + 起价 | `act.property_id` | 重排 / 删除 |
| 📍 地点停靠 | 紫 | 类别图标(🏖🗼🛒…)+ 名字 | `act.place` | 重排 / 删除 |
| 🎬 转场 | 靛(连接符) | 弧线箭头 + "挑高抛远 / 切" + 时长 | `act.transition_out` / 段间 flyover | 类型(挑高/直切)+ 时长 |
| 🎥 镜头动作 | 蓝 | 🔄旋转 / ✈️飞行 / 🔍推近 + 参数 | `beat.camera[]` | (引擎已恒速旋转;主要看,少改) |
| 🃏 卡片(overlay) | 琥珀系,见下 | 各子类缩略 | `beat.overlays[]` | 移动 at / 裁剪时长 / 删除 / 加 |

**卡片子类型(都要"显示东西"):**
- 🏠 房源卡 `property_card` → 显示**房源图片** + 名字
- 📈 ROI 卡 `roi_card` → 显示 **+X%** 大字
- 🎞 媒体 `media` → 显示**视频/图缩略图**
- 📏 距离线 `distance_line` / 🌐 配套放射 `amenity_spokes` → 图标 + 标签
- 📊 证据卡(运行时,经纪不直接编辑)

## 3. 布局(两层时间线)
```
[时间刻度尺 0s ─ 5s ─ 10s ─ … 可缩放]
┌─ 故事主线(停靠节点用转场节点串联)──────────────────────────┐
│  🏠房源A ──🎬转场──> 📍海滩 ──🎬转场──> 🏠房源B   [＋加停靠]   │
├─ 该段细节轨(随选中停靠展开 / 或常显)────────────────────────┤
│  🎥镜头:  [推近]      [环绕────────]                          │
│  🃏卡片:     [🏠房源卡▮▮]   [📈ROI▮▮▮]   [🎞海景视频▮▮]  ← 按时间对齐,可拖 │
└──────────────────────────────────────────────────────────┘
[右侧面板:选中节点的详细编辑 — 旁白 / AI意见 / 卡片增删 / 媒体]
```
- **上层 = 故事主线**:停靠大节点(带缩略图)+ 转场小节点,最直观,客户一眼懂顺序。
- **下层 = 细节轨**:镜头 + 卡片按时间排布;卡片是可拖的片段。

## 4. 交互
- **拖动**:卡片节点左右拖 = 改出现时刻(`at_ms`);右端拖 = 裁剪时长(`duration_ms`)。停靠节点拖 = 重排顺序(MVP 用 ←→ 按钮,后续真拖)。
- **点击节点** → 右侧面板编辑(旁白、AI 意见、该节点属性)。
- **点击空白**(卡片轨某时间点)→ 弹"加卡片"菜单(房源卡/ROI/媒体/距离线)→ 在该 beat 的该时刻插入节点。
- **✕** 删除节点 / 停靠。
- 每次改动后端**快照版本**,可回滚。

## 5. 数据映射(节点 ↔ TourScript)
- 停靠节点 = `intro` / 各 `act`(property 或 place)/ `outro`。
- 转场节点 = `act.transition_out`(类型+时长);段间相机由引擎从坐标算挑高弧。
- 镜头节点 = `beat.camera[]`(orbit/flyover/keyframe)。
- 卡片节点 = `beat.overlays[]`(type + at_ms + duration_ms + 各类型字段)。
- 绝对时间 = 前序 beats 时长累加 + overlay.at_ms。

## 6. 后端补充(为"卡片显示内容" + "添加节点")
- `/sessions/:id/script` 的每个 overlay 摘要补 **可视字段**:`image`(房源卡→房源图;媒体→url)、`value`(roi→growth_pct)、`media_kind`。需 join `lt_session_properties.snapshot`(取房源 image/name)+ 读 overlay 自身 data/url。
- 新端点 `POST /sessions/:id/beat-add-overlay`{beat_id, type, at_ms, duration_ms, ...}:在 beat 插入一张卡(房源卡需 property_id;媒体已有 beat-media;ROI 用该 act 房源的 investment)。
- 转场编辑 `POST /sessions/:id/stop-transition`{act_index, type, duration_ms}。
- 复用:`beat-overlays`(移动/裁剪/删)、`move-stop`/`delete-stop`/`add-stop`、`beat-media`、`revise`、PATCH narration。

## 7. 分步落地
- **N1**(本次):转场节点(串在停靠之间,可编辑类型/时长)+ 卡片显示内容(房源图/ROI%/媒体缩略)+ 后端 flow overlay 补可视字段 + 转场编辑端点。
- **N2**:点击卡片轨空白 → 加卡片菜单 + `beat-add-overlay` 端点。
- **N3**:停靠/卡片真·拖拽重排;镜头节点可视化。
- **N4**:播放头 + 预览联动;节点缩略图(地图/卡片快照)。
- **N5**:卡片库(从侧栏拖卡进时间线)。

## 8. 风险
- 卡片缩略需要房源图(R2,有 CORS 代理可用)。
- 添加卡片要保证引擎能渲染(overlay 类型 + 必需字段齐全,zod 校验)。
- 拖拽精度:用 px/s 换算,松手写回 ms。
