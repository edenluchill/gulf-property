# 实时带看（Live Tour）修复清单 —— 2026-07-14

owner 实测（`/?livetour=1&host=FUPSU`）报的 8 个问题。**一个一个修，修得 elegant 一点。**

---

## 1. 每次平移 / zoom，客户屏幕「震动」半秒 🔴

**现象**：经纪一动地图，客户屏幕抖一下（约 0.5 秒）才稳定。

**怀疑**：跟随循环（`useCollabFollow`）的 rAF lerp 与 MapLibre 自身的惯性/缓动**互相打架** ——
两边都在改相机，谁也不让谁。或是 20Hz 包 + 每帧 lerp 的收敛判据太松，来回过冲。

## 2. 经纪用电脑/iPad 分享 → 客户手机上「看得巨小」 🔴

**已有机制**：`zoomOffsetForViewport()` 让客户视口成为经纪视口的**超集**
（`dz = log2(min(myW/pw, myH/ph))`）。

**问题**：超集 = 客户看到的**比经纪多**，于是经纪想让他看的东西**变小了**。
经纪 iPad 横屏、客户手机竖屏，宽高比差异极大 —— 「超集」在竖屏上意味着大量无用的上下留白。

**要的是**：客户能**看清经纪在讲的东西**，而不是「不丢内容」。

## 3. 指标切换（如增长率热力图）不 sync ❌
## 4. 项目显示开/关 不 sync ❌
## 5. 筛选（如交房日期）不 sync ❌

三条同一个根因：**只有相机、光标、画笔在同步；地图的「状态」完全没进协议。**
经纪在自己屏幕上切了指标/筛选，客户看到的还是原样 —— 两个人在**看不同的地图**。

## 6. 聊天没有未读提示（双向）❌

客户发了消息，经纪不知道；经纪发了，客户也不知道。
**要的**：对话按钮上一个红点 + 条数，够了。

## 7. 经纪**自己看不到**自己画的东西 🔴

画笔/文字/标记会出现在**客户**手机上，但**经纪自己的地图上没有**。
（说明广播是通的，本地渲染断了。）

## 8. 画的东西图层太低 + 画图时会触发地图事件 🔴

- 线条/文字/标记应该在**最高层**：盖住项目卡、POI、地铁线、区域块 ——
  **除了** filter / 面板 / 指南针这些 UI 组件。
- 画图时**不该触发任何地图上的 hover/点击**（项目卡 hover、areablock hover），
  否则鼠标状态乱跳，画起来很怪。

## 修复顺序（按「客户能不能用」排）

| | 问题 | 为什么先修它 |
|---|---|---|
| P0 | 7 + 8 画笔（本地不显示 / 图层 / 事件穿透） | 画笔是带看的核心动作，现在经纪等于**闭眼在画** |
| P0 | 1 相机震动 | 每一次操作都在发生，客户全程晕 |
| P0 | 2 手机上看得太小 | 「经纪 iPad + 客户手机」是**最常见的组合** |
| P1 | 3/4/5 地图状态同步 | 两个人在看不同的地图，讲的东西对不上 |
| P1 | 6 聊天红点 | 消息石沉大海 |
