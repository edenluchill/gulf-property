# 功能规格:经纪人接口与订阅(Agent Portal)

> 即合伙人反馈⑤"经纪人端口 + 免费试用 + 订阅付费"。本文档为独立、系统自洽的功能规格。
> 关联:`pinzos-design-spec.md` 功能 G;`pinzos-feature-transaction-truth-spec.md`。
> 日期:2026-05-15 · 状态:待评审 · 服务对象:有成交能力的独立/小机构经纪人(付费)

---

## 1. 一句话定义

给**有成交能力的独立/小机构经纪人**一个工具:用真实 DLD 数据,一键生成 Dubai-specific、带自己品牌的客户对比报告与投资测算,让他在客户面前显专业、**多签一单**。不是又一个抢线索的门户,不是通用 AI 文案器。

---

## 2. 基于调研的关键纠偏(必须先认同)

合伙人原始设想:299/月(早鸟 199)做 AI 区域分析+文案;999/月 top 100 给"优先线索分配+专属曝光"。调研结论要求调整:

1. **删掉"优先/独家线索分配"作为卖点。** 线索分发被 Bayut/Property Finder($525M 融资)与 dubizzle(已 IPO)垄断;第三方承诺"独家线索"正是市场上"收 AED 5k–250k 预付费"骗局的特征,**经纪人对此信任已被败坏**。新进入者做"线索"几乎必败。→ 改为帮经纪人**转化他已有的线索/客户**,不承诺给线索。
2. **纯 AI 文案不能单独卖。** 实证:"买了 ChatGPT 写两次房源描述就弃用",粘性极低。→ 文案只作捆绑功能,不作核心卖点。
3. **核心付费理由 = "帮我多签一单",不是"帮我省时间"。** 省时间类(CRM)已被 PropSpace(AED 220/席)、Zoho 压到 AED 50–200。一单佣金 AED 40k–150k,经纪人愿为"能赢得客户信任、促成交"的数据工具付费——这是唯一硬付费意愿(eXp/行业实证:"data-backed insights builds client confidence")。
4. **定价重定锚。** 甜区是 **AED 199–399/月**(卡在 PropSpace AED 220 与 Property Monitor AED 500+ 的空白带)。早鸟 199 合理。**999/月 不对单兵现实**,仅对小机构/团队席位或头部 producer——重定位为"团队/机构版",不是"top 100 个人"。
5. **目标人群收窄。** 95% 迪拜经纪是纯佣金、自费 3–4 个月生活费的新人——他们最痛但最没钱,且靠机构发工具。**不要把新人当付费目标**;面向有成交能力的独立/小机构经纪人,新人走免费引流层或机构 B2B 打包。
6. **定价透明本身是差异化。** 所有对手(Reidin/Property Monitor/Property Finder)都"联系销售"不公开价。Pinzos 公开标价 + 无长锁定合约(对手普遍 12 个月锁定,经纪人怨声载道)即差异点。

## 3. 目标用户与价值

| 用户 | 痛点(调研实证) | 本产品给的价值 | 付费意愿 |
|---|---|---|---|
| 独立/小机构有成交能力经纪人 | 客户用 DXBinteract/DLD 反查,说法被当场拆穿,信任崩 | 一键生成 DLD 数据背书、带品牌的客户报告 | **硬**(能多签一单) |
| 同上 | 现有 AI 工具通用、非 Dubai-specific、客户一眼看穿 | Dubai 本地化区域分析、项目对比、投资测算(复用功能 C/D/E) | 硬 |
| 小机构/团队负责人 | 想统一团队对外材料专业度 | 团队席位、统一品牌模板 | 中-硬 |
| 纯佣金新人 | 最痛但无预算 | 免费引流层(限量功能) | 弱(不作付费目标) |

**红线**:买家端信任功能(成交真相、价格体检、区域判断)**永久免费**,绝不进经纪付费墙。订阅卖的是经纪人的**生产力/可信度工具**,不是阉割买家体验。

---

## 4. 功能范围

### 4.1 纳入

1. **DLD 数据支撑的客户报告生成器** ⭐核心付费理由
   - 经纪人选区域/项目 → 一键生成可下载 PDF:真实成交对比、净收益测算、5 年投资预测(区间制,复用 design-spec 功能 E 与 `investment-calculator`)。
   - **带经纪人/机构品牌**(logo、联系方式、RERA 号)。
   - 多语言(EN/AR/RU/ZH)——迪拜买家国际化,通用工具不支持。
2. **Dubai-specific 区域分析与项目对比**(复用 design-spec 功能 C/D,经纪人视角封装)。
3. **开发商演示模式**(design-spec 功能 A2):开发商账号默认只看自有项目 + 可叠加竞品对比。归入此处的角色系统统一实现。
4. **角色与账号体系**:agent / developer / agency-admin / platform-admin(扩展现有 Supabase Auth)。
5. **试用与订阅**:注册即 14–30 天免费试用;到期降级为免费引流层;**无长锁定合约**(对手差异化)。
6. **(捆绑,非卖点)多语言房源/营销文案生成**——作为订阅附带,不单独定价宣传。

### 4.2 明确不做

- ❌ 承诺"优先/独家线索分配"——信任雷区,门户垄断分发。
- ❌ 自建挂牌门户与 Bayut/Property Finder 抢线索——对方 $525M 弹药,必败。
- ❌ 纯 AI 文案器单独售卖——粘性低,红海。
- ❌ 把新人当付费主力——无预算。
- ❌ 12 个月锁定合约——对手通病,反做成差异化(月付可退)。

## 5. 订阅设计(重定价后)

| 档位 | 价格 | 对象 | 包含 |
|---|---|---|---|
| 免费引流层 | 0 | 全部经纪人/新人 | 基础区域查看、限量报告(带 Pinzos 水印、限次/月) |
| 试用 | 0 / 14–30 天 | 新注册 | 全功能体验,倒计时 + 到期降级 |
| 个人版 | **AED 199 早鸟 / 299–399 正式 / 月** | 独立/小机构有成交能力经纪人 | 无限品牌化客户报告、区域分析、项目对比、投资测算、多语言、无水印 |
| 团队/机构版 | **AED 999/月起(按席位)** | 小机构/团队(替代原"999 top100 个人") | 个人版全部 + 多席位 + 统一品牌模板 + 团队管理;**不含"独家线索"承诺** |

支付:迪拜可用渠道(Stripe / Telr / Network International)——需商业拍板。月付、可取消、无长锁定。

## 5b. 架构图(本模块很薄,全部复用)

```
经纪人 / 开发商 注册 → 选角色
        │
        ▼
 Supabase Auth(扩展角色)
 roles: agent | developer | agency-admin | platform-admin
 subscription: 试用(14-30天) → 个人版/团队版 → 到期降级
        │
        ▼
 经纪报告工作台(前端):选 区域 / 项目 / 客户目标
        │
        ▼
 报告生成器(主 API)── 全部复用,不重造 ──┐
   ├── market-analytics      → 功能 C 区域分级 / D 价格体检
   ├── investment-calculator → 功能 E 5年测算(区间+免责)
   └── 品牌注入(logo/RERA/联系)+ 多语言(EN/AR/RU/ZH)
        │
        ▼
 导出 PDF / 可分享链接
        │
        ▼
 支付(Stripe / Telr / Network)月付 · 无锁定

 ⚠ 买家端信任功能(B/C/D)始终免费,不进此付费墙
```

> 关键:本模块自身逻辑很薄,价值全靠复用 B/C/D/E。故严格排在它们之后(P2),否则无内容可卖。完整系统图见 `pinzos-architecture.md` 第 4 节。

## 6. 用户体验(用户旅程)

1. 经纪人注册 → 选角色 → 14–30 天试用自动开启,顶部显示倒计时。
2. 进入"客户报告"工作台 → 选区域/项目/客户目标(投资/自住/兼具) → 一键生成 → 预览 → 填品牌信息 → 导出 PDF / 生成可分享链接。
3. 报告内嵌 design-spec 的功能 C(区域判断)、D(价格体检)、E(投资测算,区间+免责)的数据,经纪人视角排版。
4. 开发商账号:登录后出现"演示模式"开关 + 竞品叠加(design-spec 功能 A2)。
5. 试用到期 → 平滑降级到免费引流层(报告带水印、限次),不锁死历史数据 → 升级引导。

体验原则:核心动作"出一份能在客户面前打动人的报告"必须 ≤ 3 步;品牌化让经纪人觉得是"他的"工具。

---

## 7. 成功指标

- 试用 → 付费转化率(按"个人版"档)。
- 付费经纪人月均生成报告数 + 报告分享/下载数(粘性,直接反驳"用两次就弃用"风险)。
- 续订率 / churn(无锁定下检验真实价值)。
- 经纪人定性反馈:报告是否真的帮其在客户面前赢得信任/促成交(对应唯一硬付费理由)。

---

## 8. 风险与待决

| 风险 | 说明 | 缓解 |
|---|---|---|
| 订阅疲劳 + AI 工具信任被骗局败坏 | 获客与留存难 | 公开透明定价、无锁定、先免费试用证明"能多签一单",不喊"AI 神话" |
| 个人 SaaS 天花板低(工具多被机构集中采购) | 纯 B2C 经纪订阅规模有限 | 同时做机构/团队 B2B 席位打包(参考 PropSpace 模式) |
| 必须先有"值得付费的内容" | 没有 C/D/E 成型,订阅无东西可卖 | 严格排在 design-spec 功能 B/C/D/E 之后(P2),不提前上付费墙 |
| 支付与发票合规(VAT) | 迪拜监管 | 商业侧确认渠道与开票 |
| 999 档定位 | 原"top100 个人"不现实 | 已重定位为团队/机构席位版,去掉线索承诺 |
