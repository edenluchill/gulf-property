# Pinzos —— 双方职责与暴雷点清单

> 日期:2026-06-30 ｜ 配套合同:pinzos-agreement-CLEAN-*(EN/中文)
> 用途:签约前对照,识别各自的义务与风险。

## 总评

对方视角 AI 评分 8.2/10 且"愿意签"。当前是"平衡但甲方占优"的健康状态,双方都有签的动力:
- **甲方**:已建资产零运营风险变现(25% 顶线抽成 + IP 永久归己 + 多条退出路)。
- **乙方**:零预付获得一套约 $20万价值的完整 AI 平台 + 75% 股权 + 100% 分红 + 品牌/客户/数据 + 融资不被卡 + 源码托管兜底。

唯一潜在阻力:25% 平台抽成偏重,对方可能想压价或加"5 年 review"(甲方已决定不改此点)。

---

## 甲方(FINDHOMEGO)职责

托管+维护平台、更新+安全补丁、~99% 可用率、**持续开发维护**、存源码进托管、履行数据处理者义务、不滥用 root。

## 甲方暴雷点

| 级别 | 暴雷点 | 说明 / 缓解 |
|---|---|---|
| 🔴 | **弃管→费率砍到 10%** | 25% 已绑"持续维护"(5.1(e))。长期撂挑子 → 对方拿托管源码 + 砍费到 10%。**维护是义务不是可选。** |
| 🔴 | **单人 key-man 风险** | 一人扛托管+维护复杂系统;病/倦/意外即崩。留文档、自动化、B 计划/备份人手。 |
| 🟠 | 可用率与单机运维 | 单机+单人真会宕机;已软化为只扣服务费,但反复严重宕机会被拼成"弃管/违约"。 |
| 🟠 | 数据/PDPL 责任 | 加拿大方握 UAE 数据 root;泄露有处理者责任且跨境。认真做 Schedule 3 DPA。 |
| 🟡 | 第三方依赖 | Gemini/Supabase/Cloudflare/DLD 涨价或停服 → 平台降级但维护义务仍在。 |

| 🟡 | 收款靠自查 | 25% 自动分账是护栏,但对方绕到平台外收款要靠审计发现。记得行使审计权。 |

注册公司 + RERA 牌照 + 合规、出全部市场/销售/人员/GTM 资金、付第三方运营成本、12 个月内投 ≥$10万、付 25% 授权费且不绕过、注册前个人连带担责、出资设托管、展示 AI 免责。

## 一句话点透

合同的真实风险不在条款,在"人":双方都高度依赖对方的单点(甲方=唯一技术大脑,乙方=唯一本地运营+出资方)。法律面已焊好,真正会爆的是:**甲方撂挑子(触发弃管)或乙方不出力/不出钱(触发丢独家)。** 甲方承诺持续维护 → 甲方侧的雷基本拆除;此后重点盯乙方的里程碑与出资承诺。
