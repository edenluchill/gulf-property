# 竞争力诚实判断 + 聚焦战略(高端尖刀)

日期:2026-06-13
要求:不讨好,用证据说话。前提:单人/小团队,资源=自己的时间。

## 判断:有没有竞争力

**作为全功能平台 — 没有(结构性差距)**
- PF 估值 $2B / 融资近 $700M;你是小团队。流量/数据/资本维度正面碰必死。
- 自认的护城河逐个不成立:DLD 数据免费公开(Dubai Pulse);投资分析 Prop-AI/PropertyGPT 已做且模型简单;地图=MapLibre 通用;语音=Gemini API 谁都能调。
- 赛道已有拿钱玩家:eVoost AI($2.2M 种子,开发商侧 语音+行为+预测)、Nexprop(经纪侧 3D+行为+评分)。
- "功能广度"对小团队是负债:样样中等深度,无一深到非你不可——稀释唯一资源(时间)。

**作为尖锐场景工具 — 有机会,但壁垒不能是技术**
- 全球 AI 导览工具不服务迪拜、不支持中/阿语、不带数据闭环;迪拜无人打通"沉浸看房+行为评分+DLD投资分析"。
- ⚠️ "没人做"可能是空白也可能是坑(客户各买点工具就够)。**必须尽早用付费客户验证,别闷头做。**

## 真正的特长(证据)
1. 执行力:单人交付生产级多模块系统(DLD 同步 / Luna Tour / 楼书提取),稀缺。
2. **中文 + 海外买家:迪拜期房 56% 海外、中国占 14%,而 PF/Bayut/全球 AI 工具都不支持中文。结构性优势,资本砸不进来。**
3. 已做出两个最难工程(楼书提取、AI 沉浸导览),别人要从零追。

## 走高端 = 对(证据)
- 高端期房 = 高客单/低走量/重体验/重信任,匹配沉浸导览+投资可信+多语。
- PF/Bayut 大众门户模式不擅长高端(走量、要价驱动、口碑 1.4/5)。
- **小团队只能靠高客单活、走不了量** → 高端让你不靠规模流量也能赚钱(生死线)。

## 聚焦战略
**砍掉**:C 端门户、大众经纪 CRM、拼 listing/流量、"什么都做"。
**留下做深(三件)**:① Luna Tour 沉浸导览 ② DLD 可信投资层(真实成交价非要价)③ 中文/多语语音+服务。
**尖刀**:给头部开发商 + 高端经纪,做面向海外(尤其中文)高净值买家的期房沉浸销售体验 + 买家行为数据。
**壁垒(非技术,技术会被复制)**:① 独家绑定头部开发商/高端经纪 ② 海外买家行为数据飞轮 ③ 中文渠道服务。

## 立刻做的一件事
找 1 个开发商或高端经纪团队**付费**,验证"真的要整合体验、愿付高价"。3 个月找不到一个愿付费的 → "三合一空白"是坑不是机会。这比写任何功能都重要。
