# Tour UX:配置繁琐 & 音频 vs Live 取舍分析

> 日期:2026-05-30
> 背景:对 `docs/agent-demo-saas-spec.md` 的体验质疑——经纪/买家流程是否太繁琐?配置能否让 AI 代劳?预生成音频 vs Live 实时接管怎么选?
> 结论性文档,供后续修订 spec 时对照。

---

## TL;DR

1. **配置繁琐是真问题** → AI 全权起草配置,经纪前台只剩「选客户 + 选房 + 一句话(可选)」,三层配置退到后台兜底。
2. **音频 vs Live 不是二选一** → 推荐 **预生成音频做主线导览 + 客户提问时无缝切 Live**;不推荐 Live 全程接管做默认。
3. **审核从"必做"改可选**(高客单价房才审),否则经纪 scale 不动。

---

## 一、配置:让 AI 代配

现状:三层 JSON 配置(平台默认 → 经纪行模板 → Session 微调),对单经纪过重(~30 字段)。

建议:
- 前台只暴露:选客户 + 选房 + 一句话意图(可选)+ 时长滑块。
- AI 用客户档案(预算/目标/国籍/家庭)+ 这句话,自动推断全部 config。
- 三层叠加保留为**幕后机制**:平台默认兜底 → 经纪行强制护栏(合规)→ AI 自动填中间层。
- 客户档案足够时,选完房即可生成,一句话都不用说。
- 默认 `auto_publish`,审核改为可选。

价值:产品从"配置工具"→"一键出片"。

## 二、音频 vs Live:看主场景

分水岭 = 异步分享 vs 同步陪同。

| | 异步分享(发链接,客户自己看) | 同步陪同(经纪在场/视频) |
|---|---|---|
| 谁在场 | 无真人 | 经纪在 |
| 最佳方案 | 预生成音频 + 提问切 Live | 全程 Live 也可 |
| playback/暂停/插嘴 | 预生成支持 playback/暂停;提问切 Live | Live 原生插嘴 |

spec 主场景 = 异步分享。该场景下**推荐预生成音频做主线**。

### 为什么不默认全程 Live
- 💸 成本失控:每个链接都烧 Live 分钟,但多数客户点开即关。
- ⚠️ 合规黑盒:实时生成无法预审,可能说出"保证回报"等违规语;预生成可审、可冻结、带 data_as_of。
- 📶 弱网/半夜:Live 要稳定连接+低延迟;预生成秒播、可缓存、可拖进度。
- 🔁 可复看:预生成是确定的"片子",可暂停/快退/重看——正好满足 playback 需求。

### 为什么仍要 Live(做提问)
- 客户暂停问"物业费?能贷款?" → 无缝切 Gemini Live 实时回答 → 答完回放。
- 体验高光;spec 原设计方向正确,只是被配置繁琐掩盖。

结论:**音频是骨架(便宜/可控/可 playback),Live 是客户主动提问才点亮的实时问答(按分钟计费,计入配额)。**

## 三、三档模式(分层)

| 模式 | 给谁 | 成本 | 体验 |
|---|---|---|---|
| 纯预生成回放 | 普通客户、海量分享 | 极低 | 可暂停/快退/重看,合规可审 |
| 回放 + 提问切 Live(推荐默认) | 有意向、会提问 | 低+按需 | 主线流畅,关键时刻可对话 |
| 全程 Live 陪聊 | VIP/高意向/同步陪同 | 高 | 像真人,随意插嘴 |

经纪一个开关切换,默认中间档。

---

## 四、降低"生成等待"

- 文本脚本秒出 → 经纪先看文字预览、改字。
- TTS 后台异步生成,经纪不干等;客户首访音频未就绪时用浏览器 TTS 兜底,高质量音频后台补。
- 买家侧不强制看完整 tour:进来自动播 30 秒速览 + 随时暂停/跳/提问。
