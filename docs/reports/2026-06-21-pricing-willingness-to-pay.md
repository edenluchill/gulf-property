# Pinzos 定价 / 付费能力分析(迪拜经纪)

日期:2026-06-21 · 问题:Agent 档 $199 是否太便宜?(用户一度以为是 199 AED)

## TL;DR(用数据)
- **199 AED($54)= 太便宜**,严重低估。**$199 美元(AED ~731)= 公允偏低**,处全球经纪 CRM 中段、远低于经纪已花的 PF/Bayut 预算。$299 常规价站得住。
- 瓶颈是**采用/信任**,不是价格 → 7 天试用 + 证明多成单 比降价重要。
- 建议:别用 $54 区间;$199 引流 / $299 常规;考虑 **AED 计价**(AED 749 / 1,099)减少迪拜经纪换算摩擦,或坚持美元但全站统一标清币种。

## 迪拜经纪赚钱能力
- 2025:39,776 持牌经纪,佣金合计 AED 137.3 亿,21.5 万笔成交,总值 AED 6,868 亿。
- 平均月佣金 ~AED 18,000(~$4,900);豪宅单笔到手 AED 100k–420k。
- 中端单笔:AED 250 万 ×2%×50% 分成 ≈ **到手 AED 25,000**;**期房开发商佣金 4–6%**(高于二手,Pinzos 正做期房)。

## 经纪已为工具付的钱(同一钱包)
- Property Finder / Bayut:单挂牌 AED 500–2,000+,套餐**一年几万迪拉姆**(≈ AED 2,000–5,000+/月)。
- 西方 CRM:Follow Up Boss $69–1,000/mo;kvCORE $99–499/mo + $1–3k setup。

## 推算
| 价格 | 占月佣金 | vs 单笔到手(AED 25k) | vs PF/Bayut | 判断 |
|---|---|---|---|---|
| 199 AED ($54) | 0.3% | 0.2% | 1/10–1/25 | ❌ 太便宜 |
| $199 (AED 731) | ~4% | 年费≈1/3 笔 | 更便宜 | ✅ 公允偏低 |
| $299 (AED 1,099) | ~6% | | 仍低于 PF | ✅ 站得住 |
| $699 Founder (AED 2,567) | | | ≈PF 套餐 | ✅ 合理(团队/重度) |

帮经纪一年多成一单(到手 AED 25k),年费 AED ~8,800 = 3×+ ROI。

## 建议
1. 价格展示**统一币种 + 标清**(目前写 $199 易被当成 199 AED → 当场被判"太便宜")。
2. Agent:$199 引流 / $299 常规(或 AED 749 / 1,099)。空间偏高不偏低。
3. 重点投入**采用**:7 天试用、案例(用 Pinzos 多成一单)、onboarding。
4. 价值锚点用经纪听得懂的:"一个工具的年费 < 半笔成交的零头"。
