# ARO.ae 互动地图竞品分析(vs Pinzos)

日期:2026-07-07
对象:https://aro.ae/interactive-map/?list=all(ARO,迪拜开发商系经纪平台,Nuxt/Vue + WebGL2 自研 3D 地图)
方法:真实浏览器逐项交互实测(点位/卡片/详情页/筛选/搜索/3D/日照/POI/动画创作器/网络请求)

---

## 一、他们的技术与产品形态速览

- **规模**:全 UAE 2,784 个期房项目(筛选面板自报数),全部落点在地图上
- **技术**:Nuxt(Vue)+ WebGL2 自研渲染(非 maplibre/mapbox 全局暴露),自定义相机(maphash = zoom/pitch/bearing/lat/lng/altitude),默认 44.5° 倾斜 3D 视角 + 3D 建筑模型渲染底图
- **数据**:`/api/v1/projects/:slug` 详情懒加载;图片 CloudFront 按尺寸切片 webp(360x240 等);GA4 埋点极细(`click_on_project_pin_on_map` 带 slug+经纬度、`is_agent` 身份区分)
- **商业形态**:开发商营销渠道 + 持牌经纪 lead gen(Book consultation / Call / WhatsApp),有账号体系(买家/经纪)

## 二、他们做得比我们好的地方(12 点)

1. **库存覆盖碾压:2,784 个项目 vs 我们 16 个**。这是最大的差距,不是 UI 而是内容。每个项目还有 unit 级数据(户型/价格/面积/楼层图)。用户打开地图"哪里都有货",我们打开地图只有零星几个点。
2. **Pin/卡片双层模型(用户点名欣赏的)**:点(pin)是永不丢失的真值层——任何缩放级别 2,784 个点全部在;照片卡片是 optional 的装饰层——有空间才显示精选卡,空间不够就隐藏,但**点击任何点必弹卡**(高清渲染图+From 价格+户型数+收藏)。清爽和信息量兼得。
3. **详情页 modal 叠在地图上 + URL 深链**:点 View details 是 overlay 而非跳页,URL 变成 `/interactive-map/project/:slug/?maphash=...`,Back 一步回地图且相机状态不丢;maphash 让任何地图视角可直接分享/收藏。SEO 每个项目一个 URL。
4. **期房销售漏斗字段化**:销售阶段五档 Announcement / Presale(EOI) / Launch / On Sale / Pending 可筛选;Sold Out 项目**不删除**,变灰点保留在地图上(悬停提示 Sold Out)——历史完整,客户不会"看到楼却查不到"。
5. **付款计划是一等公民**:筛选器可按付款比例筛(20/80、30/70…70/30);详情页付款计划可视化(20% 首付 / 45% 建设期 / 35% 交付,含附加费用说明)。这是期房买家的核心决策变量。
6. **Unit 级可售信息**:户型占比环形图(1BR 8% / 2BR 46% / 3BR 46%)、价格与面积区间筛选、每档 From 价格+起始面积、12 张楼层平面图可按卧室/类型筛。且诚实标注数据更新时间免责声明。
7. **Brochure 双按钮**:Download brochure(原版)+ **Generate brochure**(动态生成个性化 PDF)——经纪营销素材一键出。
8. **相机动画创作器**:7 步向导,在地图上逐帧取景生成 fly-through 动画视频,经纪可自制项目营销片。配合日照滑块(拖时间轴看日照/夜景+Bright map 切换)和 2D/3D 一键切换,演示 wow 感强。
9. **转化路径密而不骚扰**:详情页右侧常驻"Reach a property expert"卡(真人持牌经纪头像、免费咨询、24h 回复、no spam、TLS 加密声明)+ Book consultation + Call + WhatsApp 三通道 + 地图角落常驻电话浮钮。信任要素(牌照、承诺)做得很足。
10. **POI 图层控制面板**:7 大类(餐饮/交通/医疗/运动/自然/购物/服务)每个子类图标级开关 + Show all/Hide all,买家可只看学校或只看地铁。
11. **全局单位偏好**:AED/USD、sqft/m² 一键切换(汉堡菜单),对国际买家友好。
12. **区域成交数据整合进项目详情**:Transactions tab 按社区聚合(Sale/Rent 切换、Overall/Villa/商业/土地分线、时间刷选、1,579 条明细表),买家不用离开详情页就能看到"这个片区最近成交"。

另值一提:埋点比我们细(pin 点击直接带项目 slug + 经纬度入 GA4),做增长分析的原料好。

## 三、他们不如我们的地方(13 点)

1. **生产环境有脏测试数据**:"This is project from aro developers module"(开发商还挂着 Emaar)作为正式项目完整可访问、可进详情页——QA 流程有洞。
2. **编码 bug**:悬停 tooltip 出现 mojibake("EywaÂ TreeÂ ofÂ Life",nbsp 编码错误)。
3. **Pin 不带项目名**:不点/不悬停完全不知道点是什么项目,找特定楼盘只能靠搜索;我们 pin 常显项目名、双项目拆双 pin。
4. **核心筛选缺失**:没有价格区间、卧室数、交付时间筛选(只有类型/阶段/付款比例/独家)。找"200 万以内 2026 年交付的两房"做不到。
5. **零投资分析**:无租金回报率、无增值率、无 5 年 ROI、无供给/稳定性指标。成交图表只是原始量价曲线,不产出结论;我们有全套口径化区域指标(租金回报=新签中位/成交中位、净回报扣物业费、回本年限、期房/现房口径)。
6. **无 AI**:没有任何助手/语音/自然语言找房;我们有 Luna(语音+文字、24 个工具、导览、区域分析、AI 找房 calculator)。
7. **无协作与分享资产**:没有实时带看、没有可分享的导览/报告;我们有 co-presence 实时带看(+Agora 人声)、经纪品牌项目报告 /r/:code、报价单 /pp/:code、分享 tour。
8. **可售数据陈旧**:免责声明自曝"2025-12-29 更新"——半年前的 availability,期房市场一天一个价,等于摆设。
9. **性能与交互反常**:首次加载 3D 底图要 10+ 秒进度条;滚轮缩放被禁用(只能双击/按钮/手势),重演示、轻效率;featured 卡片互相重叠遮挡(实测 Tonino 卡叠在 Parkway 卡上)。我们地图秒开、交互原生。
10. **纯英文**:无中文/多语言;我们中英双语(区域名/介绍/Luna 中文),对中国买家是决定性优势。
11. **只有一手期房视角**:没有二手成交、租赁市场全景;我们接了 DLD 全市场每周成交+租约数据。
12. **POI 只是图标**:无照片、无介绍、无学校评级;我们 POI 弹窗有照片+中英介绍+KHDA 徽章。
13. **中立性弱**:本质是开发商/经纪的营销漏斗,所有内容导向"约咨询";我们的分析立场(真实 DLD 数据、口径公开、ⓘ如何计算)更可信。

## 四、竞争力判断

**不是同一场仗,但护城河互补方向相反:**

- ARO 的护城河 = **内容供给**(2,784 项目 × unit × 付款计划 × 楼书)+ 视觉营销(3D 城市/动画/日照)。它是"期房营销分发渠道"。
- 我们的护城河 = **数据与智能**(DLD 全量+口径化指标+AI+协作带看+经纪 SaaS 工具链)。我们是"投资决策与经纪作业平台"。

短期真正的威胁不是它的 3D 炫技,而是**库存差距**:客户在 ARO 能查到任何一个期房项目,在我们这只有 16 个。UI 我们两周能追平,内容不行。

## 五、建议吸收的(按 ROI 排序)

| # | 借鉴点 | 成本 | 说明 |
|---|--------|------|------|
| 1 | **Pin/卡片双层模型** | 中 | pin 永不丢(保留现有常显名);加"精选照片卡"图层:有空间(碰撞检测)时对高分项目显示 照片+From价格+户型数 卡;点击任意 pin 必弹卡。符合用户已认可的交互。 |
| 2 | **项目库存扩容** | 高但必须 | 战略级:楼书上传管道已在(uploader 角色/蕾姐),要把项目数从 16 推到几百。没有货,地图再好也是空城。 |
| 3 | **maphash 深链** | 低 | 相机状态进 URL,任意视角可分享/收藏;我们已有 tour code,补普通 URL 状态即可。 |
| 4 | **付款计划前置** | 低 | payment_plan 数据我们已有(报价单在用):加进项目详情可视化 + 地图筛选(20/80 等档位)。 |
| 5 | **卡片显示 From 价格** | 低 | 我们 pin 名字已常显,再加起价一行,信息密度立刻上来。 |
| 6 | **销售漏斗对齐** | 低 | 我们刚做五档销售状态,可对齐 Announcement/EOI/Launch/OnSale 漏斗语义,并让 Sold out 灰点保留不消失。 |
| 7 | **详情 modal 化 + 状态保持** | 中 | 我们地图已常驻不卸载(persistent map),详情页改 overlay+路由,返回零成本。 |
| 8 | **单位切换** | 低 | AED/人民币(我们客群)+ sqft/m² 全局偏好。 |
| 9 | **Unit mix 可视化** | 低 | 已有楼书解析的 unit 数据,画户型占比环+区间即可。 |
| 10 | **Generate brochure** | 中 | 已有报价单/品牌报告引擎,补一个"项目 brochure PDF"模板。 |

**不建议学**:重 3D 渲染底图(加载 10+s、开发成本巨大,Esri 卫星+3D extrusion 够用)、相机动画编辑器(我们的实时带看+Luna tour 概念更强,真需要营销素材可在 tour 引擎上加"导出视频")、日照滑块(纯 wow,优先级放最低,MapLibre sky/light 可低成本仿)。

## 六、他们的可借鉴工程细节

- 图片 CDN 尺寸前缀变体(`/360x240/project/{uuid}.webp`)——我们 POI/项目图可仿
- 详情按需 `/api/v1/projects/:slug`,列表只发轻量点数据
- 埋点带业务实体(slug/经纬度/is_agent),漏斗可直接按项目切
- availability 数据带"最后更新时间"免责声明——诚实是信任资产(但别像他们真的半年不更新)
