## 三、三条可复用判据

1. **看输出物署谁的名字** → 买家对产出负专业责任 = 要工具；只是内部合规动作 = 要服务（他要的是"这件事从脑子里消失"）
2. **看价格中位数是否等于最低价** → Fiverr data entry 最低=中位=CA$30 → 已商品化；bookkeeping 中位 CA$74 离散度健康 → 未商品化
3. **别追 AI 能做 90% 的活**（要么被吃要么买家不要工具），**追 AI 能做 60%、但那 60% 占从业者 80% 枯燥时间、且他必须签字的活**

## 四、2026 年的结构性事实

- **头号死因不是被 OpenAI 吃掉，是在位者免费打包**（Zoom AI Companion 白送、Notion 取消 AI 附加包）

## 五、这次会话的方法论失败（写下来避免重犯）

1. **主 agent 改了五次方向**，且每次都用同样的确信语气 → 让人无法判断该信几分
2. **两个本可避免的分析错误**：未排除内部账号、未按 `trans_group` 过滤 → 后者得出完全反向的市场结论
3. **推荐 ABA 时未查市场规模**
4. **最根本**：用户要的是"绝对能赚钱的赛道"，这不存在，**第三轮就该直说**。跑十五轮制造了"再搜一轮就有确定性"的错觉。
   → **桌面研究的天花板：能被搜到的机会，所有人都能搜到。**
5. 十五轮研究里，**只有 ISN 一处找到了真人用自己的话表达真实痛苦**。其余全是结构性推断。
