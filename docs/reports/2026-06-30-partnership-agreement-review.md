# Pinzos 合作协议(Gemini 草稿)风险排查

> 日期:2026-06-30
> 背景:用户(Party A / Findhomego Inc., Canada)独立完成整个 Pinzos 项目。计划:自己拿 25% 股权 + 25% 分红,给对方(Party B / Dubai 运营团队)75% 股权,代码所有权归自己。
> 目标:双方都有利可图(win-win)。
> 审阅对象:Gemini 生成的 "BINDING MEMORANDUM OF UNDERSTANDING — Strategic Technology Licensing & Founders' Charter"。
> ⚠️ 以下是风险排查,不是法律意见。跨境 Canada↔UAE + 房产经纪牌照 + 数据合规,签署前必须找 DIFC/UAE 本地律师。

---

## 核心结论

文件方向正确(用户保留代码 IP + 拿少数股权 + 顶线授权费,是合理的"技术方"结构),但:
- **保护用户的条款(股权、治理、执行)最弱**;
- **抽用户钱的条款(kill switch、25%毛收入)最狠**;
- 两者正好反了,需要对调。
- 而且整体太偏向 Party A,可能吓跑 Party B,与"双赢"目标矛盾。

---

## 一、三重叠加:用户实际拿的是"三份钱"

用户以为只拿 25% 股权 + 25% 分红,但文件(4.1 / 4.3)实际是:
1. 25% 毛收入(Gross Revenue)授权费(顶部先抽)
2. 25% 股权
3. 25% 净利润分红

**风险**:先抽 25% 毛,对方出全部资本+劳动却只能分抽后净利润 → 对方大概率视为陷阱而拒签/反悔。
**建议**:25%毛 与 25%股权+分红 二选一为主,不要全拿满。

## 二、真正会伤到用户的漏洞

1. **净利润分红必被做空(好莱坞会计)**:对方控盘全部成本(5.2),可把净利做到≈0。→ 命根子是 4.1 的 25% 毛收入(top line),守死;分红当补充。
2. **MOU 且无管辖法/仲裁地/争议解决**:跨境等于无执行手段。→ 补 governing law + 仲裁(DIFC-LCIA 或 DIAC)。
3. **25% 股权靠 MOU 拿不到**:必须落进 Dubai 实体章程/股东协议/cap table。对方实体尚未注册,pre-incorporation 合同执行力弱。
4. **少数股权太弱**:可被增发稀释,无董事席位、无否决权。→ 加反稀释/优先认购、董事席位、重大事项否决;章程重大决议门槛设 ≥75% 使 25% 成为 blocking stake。
5. **Kill switch + root access 会反噬**:与 3.1(数据归 B + UAE PDPL)冲突,构成跨境数据/控制者责任;停服会引对方客户→对方→用户的索赔链。→ 写成"有条件行使"(书面通知+补救期+明确违约情形),别写 absolute/unilateral。
6. **独家锁死整个 GCC 却无业绩门槛(2.2)**:对方只做 Dubai 即可霸占 GCC。→ 加最低营收/里程碑,未达则独家降级/收回其余市场。
7. **散伙时用户亏(6.2 + 3.1)**:对方拿走品牌+客户名单+数据,用户只剩代码+匿名数据,从零重启。→ 争取退出数据副本权、品牌归属重谈、客户/员工竞业不撬。

## 三、完全缺失、必须补的条款

- 保密 + 禁止反向工程(护城河=代码/架构,现在零保护)
- 责任限制/免责(平台做 ROI 投资预测,客户亏损可能追算法作者;写明 AI 输出非投资建议 + 责任上限 + 对方 indemnify 本地使用/宣传)
- 第三方成本归属(Gemini/Supabase/Cloudflare/R2/Stripe 云费与 API 费谁付,写死,别让用户拿 25% 却自贴)
- 退款/chargeback 对账机制(4.1 点对点抽成后如何回冲)
- 期限/续约(现无期限=永久)
- 限制对方转让/控制权变更
- 税务(UAE 9% 企业税/可能预提税 + 加拿大端报税,提前找会计设计)
- UAE 房产经纪牌照(RERA)+ 外资持股合规确认

## 四、结构建议

拆成三份正式文件,不要用一份 MOU 打包:
1. **Technology License Agreement** —— 25% 毛收入 + IP 归属 + 独家/业绩门槛 + kill switch 条件(用户的钱和护城河)
2. **Shareholders' Agreement + 公司章程** —— 25% 股权 + 反稀释 + 董事席位 + 否决权(股权的真正载体)
3. **数据处理附录** —— 解决 root access 与 PDPL 冲突

并先决定 25%毛 vs 25%股权+分红 主打哪个;全拿满 ≠ 双赢。签前必须过 DIFC/UAE 律师。
