## ① `/cr/:code` 中英混杂 —— 根因不是漏翻,是**提示词污染**

owner 实拍:一份 **英文** 报告里写着

```
Top pick · 1 Bedroom · 1 房 · 1 卫 · 757.46 ft²
```

第一反应会去找"哪个 i18n 键漏了"。**找不到** —— 这行字根本不经过 i18n:
它是 AI 生成的 `recommended_unit`,而 AI 是照抄提示词里的中文。

`backend/src/luna-tour/client-fit-analyzer.ts` 的 `unitLines()` 把喂给模型的
户型清单拼成 `${u.bedrooms} 房 · ${u.bathrooms} 卫 · 阳台 …`。
提示词是上下文没错,但**模型会把上下文里的字面量原样搬进输出**。

同一个病在这条链路上一共四处,按"漏得多严重"排:

| 位置 | 是什么 | 会怎样 |
|---|---|---|
| `unitLines()` | 逐条枚举的户型行 | 漏得最狠,整行被抄走 |
| `fails.push('没有女佣房')` | 硬伤原因 | 跟着户型行一起抄 |
| `profileLines()` | 客户画像上下文 | 散文式,模型多半会改写,但仍会漏词 |
| `POLICY` / `radarScores()` | **不是提示词,是直接印在报告上的成品** | 100% 中文 |

处置:全部按 `lang: LangCode` 出。前两处五语言全写,`profileLines()` 只做
中/英两套 —— 它是上下文不是成品,英文上下文漏进法/俄/阿基本无害,而中文漏进
英文很刺眼。

> 🔴 判据一句话:**这段文字会不会出现在给客户的成品里?** 会,就不能写死一种语言。

## ② 「Match 4」—— 量表没告诉模型

`FIT_SCHEMA` 里 `project_fit: N('number')`,**没写范围**。模型自己挑了个 0-5 的
量表返回 4;前端按 0-100 画进度条 → 客户看到「Match 4」和一条几乎空的条。

两头都修:
- schema 的 `description` 写死「0-100 的整数,60 以下=勉强,90+=极其合适」
- 前端 `< 20` 直接不显示 —— **显示一个错的分数比不显示更伤**

## ③ 报告排版:AI 一直在写结论,但从来没人渲染

`FIT_SCHEMA` 有 `summary` 字段,后端每次都生成、每次都存进库,
**前端的提案视图从来没有渲染它**(只有 compare 视图渲染了)。

客户点开链接的第一屏是:项目名 → 雷达图。他要的第一句话("所以呢")
一直躺在 JSON 里。现在提到 hero 下面,带一条青色竖线。

同屏顺手修的三处:
- 开发商为空时标题下面留着一个孤零零的 `·`
- 评分块 `self-stretch` 让条形右边空出约 200px 死白 → `items-center`
- 雷达 `viewBox` 只按中文轴名长度留了余量,英文 `Growth potential` 被切成
  `Growth potentia`;条形轴名 `w-20` 在英文下折两行

**教训**:布局宽度必须按**最长的那个语言**定,不是按开发时看的那个。

## ⑤ 买家匹配页 —— owner 看到的是**空白**,因为他是内部账号

`DispatchStatusCard` 对内部账号 `return null`(对他们确实没意义),
列表也永远是空的(内部号不进派单池)。两个"合理"的判断叠在一起 =
owner 打开这页什么都没有,结论自然是"这页没用"。

修了三件事:
1. 内部账号给一条明说的说明栏,并指向 admin 的派单面板
2. **信息栏**:当前轮次 / 本轮排位 / 累计派单 / 买家要了联系方式 / 待跟进
3. 历史**按轮分段**(`/mine` 补返回 `round_no`)+ 全部/待跟进/已跟进筛选

> 派单是轮值制,「第 3 轮」比「8 月 7 日」更能说明"我在这一轮里拿到了"。

## ⑥ 工作台:第一屏没有一个数字

原来第一屏 = 六条通知卡片 + 两张深色渐变大卡,**零个数字**。
经纪看完不知道该干什么。

- 顶部换成四个**要采取行动**的数(跟进逾期 / 我的客户 / 派单排位 / 买家要了联系)。
  累计打开数这种虚荣指标留在页尾的表现区。
- 通知(`IntentFeed`)缩成一条窄栏,**有未读才自动展开**。
  收放状态用 `useRef` 不用 `useState` —— 轮询用的是 `useEffect([])` 里那份闭包,
  用 state 的话用户收起来下一分钟又被弹开。
- 两个 tour 入口从"一张墨黑一张青绿渐变"改成和全站同一套白卡:
  色块比字还响的时候,它看起来像广告不像工具。

### 三次假红灯(harness 的教训)

| 症状 | 真因 |
|---|---|
| 「匿名看不到找真人入口」 | 断言写的 `/经纪\|Agent/`,而**中文标签是「找真人」** |
| 「手机没有找真人入口」(时有时无) | 固定 `sleep 3.5s`,那个入口要等 `/agent-match/next` 回来才渲染 |
| 「手机没有 ROI 入口」(时有时无) | 户型卡片网格懒渲染,第一次点可能落在还没挂 onClick 的占位上 |

**断言要按目标语言的实际文案写,等待要等真正那条响应。** 固定 sleep 两个方向都会骗人 ——
这三条里有一条是真 bug(手机 ROI 入口),两条是我自己造的噪音。
