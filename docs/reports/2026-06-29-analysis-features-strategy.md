# 「分析」功能去留 + 网站利益最大化策略

日期：2026-06-29　作者：Claude（基于生产真实数据）

用户问：「分析」下拉里的 3 个功能（区域分析 / AI报告 / 对比）有必要提供吗？它们 outdated 了；是不是该改成"经纪帮客户生成对比"更好？怎么让网站利益最大化？

## A. 数据判据（真实客户，已排除内部测试号）

真实客户 page_view 按页面：
| 页面 | 真实访问 | 真实人数 |
|---|---|---|
| 地图/首页 | 336 | 177 |
| 项目详情 | 48 | 28 |
| 成交记录 /transactions | 23 | 12 |
| 经纪报告 /r/ | 4 | 2 |
| **区域分析 /areas** | **0** | **0** |
| **对比 /compare** | **0** | **0** |
| **AI报告** | **0** | **0** |

结论：散客流量 100% 在 **地图 → 项目详情**。「分析」下拉那 3 个散客自助功能 ≈ 零使用。

## B. 判断

1. **作为散客自助 tab：砍/降级。** ① 零使用 ② outdated（且底层是修过 500 的 area-insights 那套，越不维护越脆）③ 散客不是付费方，给散客堆自助分析是力气用错地方。
2. **能力本身有价值，应改为"经纪→客户交付物"（用户点子对）。** 对比/AI报告是**决策阶段**工具，决策阶段=成交发生、经纪体现价值、平台收钱处。应做成：经纪给具体客户攒 shortlist → 一键生成**带品牌、可分享、可追踪**的对比/决策报告 → WhatsApp 发客户。对齐已有 `/r/:code` 经纪品牌报告（唯一有真实使用者）+ B2B2C 转型。

## C. 利益最大化（钱=经纪订阅）

最大化 = 经纪多成交 + 显专业 + 留得住。三动作：
1. **火力压到真实在用的漏斗**：地图→项目详情→经纪帮决策→联系。停投零使用散客 tab。
2. **经纪在决策阶段当主角**：shortlist→品牌化对比/报告→分享→追踪→促成。付费价值点 + 病毒传播（客户收品牌报告→看到 Pinzos→潜在新经纪/lead）。
3. **数据闭环当经纪每日留存钩子**：把"失去的客户/该联系的人/意向分"按每个经纪切分，经纪每日登录看自己客户管线（谁热/谁被block/谁要流失）。续费理由。

## D. 具体改法
- **收掉「分析」下拉**：`对比`/`AI报告` 挪进**经纪台**，做成"为某客户生成"（绑客户/带品牌/可分享/可追踪）。
- `区域分析` 分级（成熟/增长/回报）+ `成交记录`：折叠进**项目详情页和报告**当佐证，不单开页（项目详情有真实流量）。
- 散客导航只留：地图 + 项目详情 + 联系。越简单越转化。

核心一句：**别给散客做分析平台，给经纪做成交武器。**

## E. 建议执行顺序
1. 收「分析」下拉 → 对比/AI报告 迁经纪台做成绑客户的品牌化交付物（最聚焦、最对齐商业模式）。
2. 区域分级/成交折叠进项目详情 + 报告。
3. 经纪台「我的客户管线」（复用 lost-customers/error-impact/意向分，按 agent 切分）。
4. 砍掉散客分析页，回收维护成本。

> 注：执行前确认这些功能确无外部经纪在用（当前看真实散客零使用；经纪侧使用需另查 /agent 相关）。

## F. 两边视角分析（买家 + 经纪的利益点/痛点）

背景：迪拜期房买家多为**远程、看 ROI 的投资客**；经纪市场**极度内卷**（人人同样的盘）。

### 买家（远程投资客为主）
- 利益点：是否好投资(ROI/回报/增值/回本)、要**真数据非套话**、价格公道(价格体检)、同预算选谁更好、有人可信地帮决策。
- 痛点：信息不对称(分不清吹/真)、远程看不了房难建信任、期房烂尾/增值风险、几百盘无从对比、语言时区被推销压力。
- 第一需求：**信任 + "值不值"**，不是更多自助工具。

### 经纪（迪拜 broker）
- 利益点：成交拿佣、显专业可信、高效转化、搞定远程客户、长周期刷存在感。
- 痛点：极度内卷难差异化、远程客户难取信易跑单、线索石沉大海看不到谁有意向、反复手工做对比/报告、对大中介显小没数据武器、客户多记不清谁热。
- 第一需求：**差异化 + 客户记住我 + 知道谁值得追**。

### 关键洞察（两边痛点互解）
> 经纪用真数据(DLD真成交+价格体检+ROI+区域分级)做**带品牌、可分享、可追踪的"决策包"**发给远程客户。
- 买家得：可信的、解"值不值"的真数据。
- 经纪得：差异化专家形象 + 客户记住他 + 看到互动。
- 附带病毒传播：客户看品牌报告→看到 Pinzos→新经纪/新买家。
→ **那些分析不是没价值，是放错位置：它们是经纪的弹药，不是散客自助 tab。**

### 逐个裁定（对经纪）
| 功能 | 价值 | 正确用法 |
|---|---|---|
| AI报告 | ⭐⭐⭐ | 旗舰；做成"经纪给某客户的决策报告"，品牌化可分享 |
| 对比 | ⭐⭐⭐ | 决策阶段神器；"我帮你对比了你看中的3个"，绑客户带品牌 |
| 成交记录(DLD) | ⭐⭐ | 信任锚；当佐证塞进报告/项目详情，不单开页 |
| 区域分析(分级) | ⭐ | 单独价值低；当报告里一句推荐理由才有用 |

## G. 推荐产品重心（含 per-agent 数据隔离）
1. **经纪台·我的客户**（私有 CRM）：经纪收集/查看自己客户——**按 agent 严格隔离(后端强制行级，admin例外)**，复用意向分/失去的客户/该联系的人按经纪切分。解"记不清谁热"，是续费钩子。
2. **决策包生成器**：经纪选客户+shortlist→一键品牌化/可分享/可追踪的对比/AI决策报告(内嵌DLD真成交+价格体检+ROI+区域分级)。
3. **收掉散客「分析」下拉**，能力归位到上面两个 + 项目详情。

核心一句：**买家要"可信+值不值"，经纪要"差异化+被记住+谁值得追"——一份经纪品牌化数据决策包同时满足两边，这是该全力压的方向。**
