## 1. 钱在漏（P0）

```js
function isLoggedIn(req) {
  return !!req.headers.authorization?.startsWith('Bearer ')  // ← 只看头存不存在，不验签
}
if (isLoggedIn(req)) { checkCredits(...) }                   // ← 不带头 = 完全跳过配额
```

**开放互联网上的任何人都能无限烧我们的 Gemini + TTS。**

修：`requireAgent` **真验签**，挂 9 个烧钱端点；**删掉 `isLoggedIn()`**（它是洞的源头）。

⚠️ **我的跑分脚本之前"不扣额度"靠的正是这个漏洞。不能用漏洞来做测试。**
改走 `x-luna-internal` + `LUNA_INTERNAL_TOKEN`。e2e 第 ⓪ 条是这个洞的**墓碑**。

## 2. 核心卖点之前是假的（P0）

行为数据一直在采（125 条），但**没有任何人被告知**。

- **高意向 → 立刻通知**：看完 / 想联系 / 收藏。站内 + **邮件**。同一访客看三遍 ≠ 三条通知。
- **工作台第一屏**就是「客户动静」，不藏在 tab 里。
- **CRM 接通**：`/clients/:id/activity` → 他在**哪几套房上停留最久**。
  > 「陈先生，我看您在 Serenz 上看了挺久」比「您考虑得怎么样了」强一百倍。

实测：真事件 → 2 条通知 + **2 封邮件已发** · 跨经纪隔离（自己 200 / 别人 404 / 匿名 401）。

## 3. ⭐ 地理套利 + 它的短板（P2）—— 真正让人产生购买冲动的部分

**投资客真正想知道的不是「这个项目涨多少」，而是「我为什么该买这里，而不是走路
5 分钟外的那个区」。这是地图能做、而 PDF 楼书永远做不到的事。**

| 区域 | 距离 | 涨幅 | 回报 | 单价/㎡ | 年成交 |
|---|---|---|---|---|---|
| **JVC**（本区） | — | 8.5% | **6.69%** | 16,084 | **14,817** |
| Arjan | 0.15km | 13.5% | 6.38% | 16,482 | 3,889 |
| JVT | 0.18km | **15.0%** | 5.90% | 17,539 | 5,242 |
| Motor city | 0.53km | **0.0%** | 4.07% | **20,236** | 4,867 |

Luna 说出口的：

> 「0.53 公里外的 Motor City，**比这里贵了 26%，但涨幅停滞为 0**。」
>
> 「坦白讲，JVC 确实不是涨得最猛的 —— JVT 涨了 15%。**但是**，JVC 一年成交 1.48 万笔，
> 是邻区的数倍。当您未来需要套现时，这里**永远有人接盘**。」

> **Allen 的元分析：说了缺点却不反驳它，比什么都不说更糟。**
> 有效的机制不是「坦诚」，是**接种** —— 让他**免疫下一个经纪要说的话**。

**反驳是代码算出来的**（`findWeakness`）。**找不到能被真数据反驳的短板 → 那一拍整个不讲。**

⚠️ **成交量门槛（>500）对邻居和自己都生效**。Al Safouh First 一年只有 **72 笔** ——
拿它比涨幅，那个百分比是随机数。

## 这一轮最贵的三个教训

**① 「LLM 会违反 prompt。代码不会。」—— 但反过来也成立：坏的代码同样赢过好的 prompt。**
我在剧本层改了三轮运镜，**一轮都没生效**，因为渲染层每帧把它覆盖掉（写死的市中心起点、
`AMBIENT_ORBIT_DEG=24`、`ROTATE_DEG_PER_MS=3°/s`）。而我从来没去看渲染层。

同一个坑第二次：prompt 写了 `kind="arbitrage"`，模型**内容一字不差全写对**，却统统标成
`"life"` → 卡片不出现。→ `classifyBeats()` 在**代码里**认。

**② 空过的断言是虚假的安全感。**
「短板必须带反驳」绿了 —— 但那轮选到的区成交量太低，那一拍**正确地跳过了**，
断言**根本没执行**。修了选盘逻辑，让这条路径每次真的走一遍。

**③ 类型在编译期是对的，运行期是错的。**
后端发 `camera: "环绕展示"`（字符串），前端 `camera?: string[]` 并 `.map()` 它 ——
**两边各自的 tsc 都通过**，用户看到白屏。没有任何编译器管这道缝。
→ e2e 加了**契约断言**。而这也暴露了跑分最大的盲区：**它只打 API，不打 UI。**
