# 想法暂存:线上沙盘互动(便宜版)+ 定价 —— 2026-07-10

> 状态:**暂存,未做**。和已 parked 的「3D 户型沙盘 + AI 带看」是同一条线(见 memory [[parked-3d-ai-tour-feature]]),
> 但这次是**更轻、更便宜、可复用现有楼书数据**的版本 + 一个关键的定价洞察。重启前先看这份 + 那条 memory。

## 核心想法
期房销售中心的核心道具是**实体沙盘**。把它搬到线上、做成**可点击的互动沙盘**:
- 一张**沙盘俯视图 / 效果图**放在地图上某个 area(或项目详情里)
- 上面画**可编辑热区**(每栋楼 / 每个单元一个多边形)
- 热区**绑定楼书里已有的户型数据**(户型/价格/付款计划 —— 我们上传楼书的部分已经有)
- 买家**点击某栋楼 → 弹出该户型信息**

**"便宜版" = 不做真 3D 建模**:只是「图片 + 可点击热区 + 映射到已有户型」。工作量中等,不贵。
核心复用件:楼书上传的户型数据(已有)+ 一个热区编辑器(新)+ 点击→户型详情(复用现有户型组件)。

## 定价洞察(这次纠结的关键,别忘)
**这个功能是"上架一个盘"性质的低频活,不是每月持续用 → 不该按月订阅。**
- 开发商上新盘时做一次沙盘互动 + 上架,之后基本不动
- 按 developer 档 $999/月 收 → 做完一个盘就想退订 → **churn 高、收入不稳,收费模式和使用频率错配**
- SaaS 月订阅只在"持续产生价值"时成立(经纪天天用客户雷达/带看那种)

**更合适:把"一次性"和"持续"拆开收**
| 价值类型 | 例子 | 收费方式 |
|---|---|---|
| 一次性(项目制) | 沙盘互动制作 + 盘子上架 | **per-listing / setup fee**:每盘 $X 一次性 |
| 持续(月月有) | 全站曝光、Luna 主动推荐、买家 lead 分发、托管展示 | 月/年订阅 |

建议形态:developer 月订阅装**持续价值**(曝光/lead/推荐/托管);**沙盘互动做成 per-listing 加购**(每盘一次性做好常年挂,更新再收小额)。或"$X/年含 N 个盘"的包给一年多盘的大开发商。

## 重启前先验证(别闷头做)
拿具体想法去问 1–2 个开发商一句话:
> "把你的盘做成买家可点击的线上沙盘(点楼栋看户型/价格),你愿意付 $X 一次性(或 $Y/年)吗?"
- 愿付定金/签 LOI → 需求证真,做便宜版(2–3 天出 demo)
- 没人愿付 → 是"自己觉得酷"、开发商不买单,省下开发时间

可选:先做**极简 demo 页**(某个盘一张俯视图 + 2–3 个可点热区 → 点击弹户型,不接订阅/编辑器)纯给谈单用,半天能出。

## 背景(工作量 vs 分成的疲劳)
2026-07-10 讨论中用户提到「后悔只拿 25%、工作量太大」。判断:更像是**scope 没边界 + 累**,不是分成谈亏了(25% 平台收入是**防稀释**的 + **代码永久归属**,底牌比数字厚)。行动上——**给需求装刹车**:分清"平台核心"vs"运营方定制"(后者可另议/额外补偿),该 park 的先 park(如本沙盘),别变成免费无限开发工。
