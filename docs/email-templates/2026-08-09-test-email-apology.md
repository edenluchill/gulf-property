# 给误收测试邮件的两位经纪的说明（2026-08-09）

## 背景

开发「买家找经纪」派单功能时，验证邮件通知链路用了生产环境，收件人是真实经纪账号。
主题写的是「【Pinzos】有买家想找你 / 新买家线索」，看起来和真实线索完全一样。

| 收件人 | 邮箱 | 封数 | 情况 |
|---|---|---|---|
| Daniel Gong | dilonggong@gmail.com | 3 | **已当真并回信**，主动联系了"买家"（实为我们自己的邮箱） |
| Xiao liu | 502579810@qq.com | 2 | 正文里带了「这是自动化测试邮件，请忽略」 |

Gong 那封要单独写 —— 他已经花时间跟进了，不能只发一句"忽略即可"。

---

## ① 给 Daniel Gong（他已回信跟进）

**主题：** 关于昨天那几封「新买家线索」——是我们的测试，给您添麻烦了

```
Gong 您好，

先跟您说声抱歉。昨天您收到的几封「新买家线索」邮件，是我们在测试新功能时
误发到了您的真实账号上，并不是真的客户。您还专门回信去联系了，白白占用了
您的时间，这是我们的疏忽。

我们正在做的功能是这样的：买家在项目页或地图上主动点「找顾问帮忙」时，
系统会按轮次把他分配给一位正在接单的经纪，并把买家的联系方式和留言发给您，
同时附上一封写好的开场邮件（按买家的语言生成，您复制就能用自己的邮箱发出）。

测试流程我们已经改掉了，不会再用真实账号发测试邮件。

功能已经正式上线。如果您想接买家，在个人资料里补上手机号就会进入排班；
分配给您的买家会显示在经纪台的「买家匹配」里。

再次为打扰致歉。

Pinzos
```

## 写这两封时遵循的（见 memory `customer-outreach-email-tone`）

- **正式 + 先致歉**，不找借口、不说"系统原因"
- 说清楚**到底发生了什么**，不含糊成"技术问题"
- 明确说**已经改掉了**，让对方知道不会再发生
- 顺势说明真功能是什么 + 怎么参与（这封信本来就是个说明的机会）
- **不写**「您还没使用过」「您的资料不完整」这类像在监视对方的话
